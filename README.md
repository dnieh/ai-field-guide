# AI Industry Field Guide

A sourced, fact-checked map of **854 AI companies** across the stack, as of October 2026.

**Read it:** https://dnieh.github.io/ai-field-guide/

## What's inside

The guide is organized by layer of the AI stack, from the bottom up, each split into categories:

| Layer | What it covers |
|---|---|
| Chips, compute & clouds | GPUs and custom silicon, chip startups, clouds and neoclouds, data centers, power and networking |
| Model labs | Frontier labs, new research labs, open-weight and enterprise model makers, China, sovereign labs, generative media, world models, science and bio |
| Dev tools & infra | Coding agents, app builders, review and testing, agent infrastructure, inference, training platforms, training data, evals and security, databases |
| Applications | Business functions (support, sales, finance, HR, security…) and industries (legal, healthcare, financial services, real estate, government, education, industrial, consumer) |
| Physical AI & robotics | Robot foundation models, humanoids, industrial robots, autonomous vehicles, defense tech |

Each detailed profile shows the latest funding round, valuation and revenue with the month it was reported, recent events, and links to every source. Shorter entries carry one dated source each.

## How it was made

Researched Oct 15–21, 2026 by AI research agents (Claude) under a rule that every current fact must come from a page actually opened, then re-checked by separate fact-checking agents against the cited sources. About 96% of re-checked claims were confirmed as written; the rest were corrected, removed or labeled. See **How this was made** on the site for the full method and its limits.

## Corrections

Spot something wrong or stale? [Open an issue](https://github.com/dnieh/ai-field-guide/issues) with a link to a better source.

## Structure

```
site/               source: React + Vite + Tailwind CSS + shadcn/ui components
site/public/data/   guide.json — all companies, categories and sources
index.html, assets/ built site (generated by `npm run build` in site/; served by GitHub Pages)
```

To change the site: `cd site && npm install && npm run dev`, then `npm run build` to regenerate the published files in the repo root.

Not investment, legal or career advice. Company names and trademarks belong to their owners; summaries are paraphrased with links to the original reporting.
